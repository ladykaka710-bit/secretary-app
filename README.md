# 秘書アプリ

自分専用の簡易秘書アプリ（メモ機能・タスク管理機能・ダッシュボード機能）です。
Node.js標準モジュールのみで動作するため、`npm install` は不要です。

## 起動方法

```bash
node server.js
```

起動後、ブラウザで以下にアクセスしてください。

```
http://localhost:3000
```

## 機能

- **メモ機能**: タイトルと本文を入力してメモを追加、一覧表示、削除、作成日時表示
- **タスク管理機能**: タスクを追加、一覧表示、完了/未完了の切り替え、削除、作成日時と完了状態の表示
- **週次振り返り機能**: 週（月曜始まり）ごとに振り返りコメントを記録・確認、過去の振り返りを一覧表示
- **ダッシュボード機能**: メモ件数・タスク件数・完了タスク件数・最新の振り返りを表示

## データ保存

入力したメモ・タスク・振り返りは `data/notes.json` ・ `data/tasks.json` ・ `data/reflections.json` に保存されます。
アプリを閉じても、次回起動時にデータが引き継がれます。

## ポート変更

環境変数 `PORT` で起動ポートを変更できます。

```bash
PORT=4000 node server.js
```

## Cloudflare Pages へのデプロイ

ローカル起動とは別に、Cloudflare Pages 上でブラウザからいつでもアクセスできる形にもデプロイできます。
手順は [DEPLOY_CLOUDFLARE.md](DEPLOY_CLOUDFLARE.md) を参照してください（`functions/` ディレクトリにPages Functions版のAPIを実装済みです）。
